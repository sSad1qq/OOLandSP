# Этап 8. Испытания варианта 6 в Windows

Скопировать папку cursach на Windows. В Visual Studio с компонентами разработки классических приложений .NET и targeting pack .NET Framework 4.7.2 открыть app/lb2.slnx (если версия IDE не поддерживает .slnx, открыть app/lb2.csproj). Выбрать Debug и Any CPU, выполнить «Сборка → Перестроить решение», затем Ctrl+F5. Записать версию Visual Studio, результат сборки и наблюдения в последнюю колонку.

Для основного теста открыть готовый файл [control.txt](control.txt). Его содержимое:

```text
2 5
4 6 9 10 6
-6 0 1 7 8
```

Для bad.txt сохранить только первые две строки. Для проверки нулевого ответа создать zero.txt из заголовка «1 5» и последней строки control.txt.

| Действие | Ожидаемый результат | Фактический результат Windows |
|---|---|---|
| Перестроить проект и запустить | Сборка без ошибок, открывается главная форма | Ожидает запуска |
| Открыть пять пунктов меню подряд и вернуться к строке | Виден только выбранный раздел | Ожидает запуска |
| Строка: ввести «жёе», нажать Enter; затем «еёёж», нажать кнопку | «еёж» и «еёёж» соответственно | Ожидает запуска |
| Проверить пустую строку и «а1» | Подсказка о пустой строке и сообщение о допустимых буквах | Ожидает запуска |
| Вектор: ввести длину 4 и вычислить; повторить с длиной 1 | Четыре числа от −106 до 106; три результата равны суммам соседей. Записать оба списка. Для длины 1 появляется сообщение | Ожидает запуска |
| Матрица: до инициализации проверить «Решить», задать нулевой размер, затем допустимый размер 2 × 5 и инициализировать | Изначально кнопка отключена. Неверный размер отклоняется. При допустимых размерах появляются таблица и путь, доступен расчёт | Ожидает запуска |
| Открыть control.txt, нажать «Решить» | Таблица 2 × 5, ответ 5: подходят 4, 6, 9, 10 и повторное 6 | Ожидает запуска |
| Сохранить как copy.txt, открыть копию и решить. Отменить открытие, затем попробовать bad.txt и повторить расчёт | Копия даёт 5. Отмена сохраняет таблицу; испорченный файл вызывает ошибку. Таблица и путь копии сохранены, ответ снова 5 | Ожидает запуска |
| Открыть zero.txt и решить | Ответ 0 | Ожидает запуска |
| График: начать построение, нажать «Нарисовать» повторно в процессе и дождаться завершения | Построение начинается заново; примерно через 20 с видна замкнутая кривая с началом и концом в (2, 0) | Ожидает запуска |
| Блуждание: проверить исходную позицию, нажать «Старт», затем «Стоп», подождать и продолжить | Начало в ячейке 38 при нумерации с нуля. При паузе позиция сохраняется; движение продолжается с неё | Ожидает запуска |
| Для проверки границ запустить с отладкой, остановиться точкой останова в начале timer2_Tick, по очереди задать nC = 0 и nC = 77 и пройти обработчик пошагово | После одного тика координата 1 и 76 соответственно | Ожидает запуска |

Сохранить реальные снимки окна через Win+Shift+S в screenshots: 01-string.png, 02-vector.png, 03-matrix.png (контрольная матрица и ответ 5), 04-chart.png, 05-walk.png. Если обнаружена ошибка, записать действие, входные данные и фактическое поведение. После исправления повторить проверку.
